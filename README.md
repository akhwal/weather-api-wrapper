# 🌤️ Weather API Wrapper

A simple, fast, and structured Express.js Weather API Wrapper service that fetches real-time weather data from external weather providers and transforms it into a clean JSON response.

---

## 🚀 Features

- **Express.js Server**: Fast and lightweight HTTP backend server.
- **Environment Variables**: Secure configuration using `dotenv`.
- **Response Transformation**: Filters and cleans up raw third-party weather API data into a simple JSON response.
- **Axios HTTP Client**: Reliable server-to-server HTTP requests.

---

## 🛠️ Tech Stack

- **Runtime**: Node.js (v24.22.1 LTS)
- **Framework**: Express.js
- **HTTP Client**: Axios
- **Environment Manager**: Dotenv
